PASS if 삭제 버튼이 링크(`<Link>`·`<a>`) 바깥에 있어서 링크와 버튼이 서로 중첩되지 않는다. 카드 전체 클릭 영역은 오버레이 링크, 가상 요소(`::after`), 또는 링크와 버튼을 형제로 둔 구조로 만든다.

FAIL if 삭제 버튼을 `<Link>`·`<a>` 안에 넣는다. `stopPropagation`·`preventDefault`로 이동만 막는 경우도 FAIL이다. 클릭은 막혀도 포커스와 스크린 리더 낭독은 여전히 꼬인다.

삭제 버튼에 접근 가능한 이름(`aria-label` 등)이 없으면 FAIL이다.

변수 이름, 코드 스타일, CSS 방식(클래스·인라인 style·CSS 모듈), 설명의 길이는 판정에 쓰지 않는다.
