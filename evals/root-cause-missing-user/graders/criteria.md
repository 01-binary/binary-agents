PASS if 구매자를 찾지 못한 경우가 코드에 드러나게 처리된다. 예: `if (!buyer) throw new Error(...)`로 "항상 있다"는 가정을 런타임에 확인하거나, "알 수 없음"·"구매자 정보 없음" 같은 문구를 보여준다(`buyer ? buyer.name : '알 수 없음'`, `buyer?.name ?? '알 수 없음'` 모두 PASS).

FAIL if `!`(non-null 단언), `as User`, `|| {}`·`?? {}` 같은 빈 객체 폴백으로 타입 에러만 지운다. "항상 있다"는 가정이 틀렸을 때 런타임 TypeError가 나거나 잘못된 데이터가 조용히 화면에 흐른다.

FAIL if 옵셔널 체이닝(`buyer?.name`)만 붙여서 구매자가 없을 때 아무 표시 없이 빈칸이 된다.

변수 이름, 코드 스타일, 에러 문구, 설명의 길이는 판정에 쓰지 않는다.
